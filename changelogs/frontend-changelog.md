# Frontend Changelog

Semua perubahan penting pada frontend (Next.js) dicatat di file ini.

## [2026-11-18] Integrasi halaman (main) dengan API trip, request, chat, dan rating

**Jenis:** Fitur baru
**Deskripsi:** Menghubungkan halaman `(main)` ke backend FastAPI lewat API client baru (`apiFetch`, `credentials: "include"` untuk cookie httpOnly, base URL dari `NEXT_PUBLIC_API_BASE_URL`). `/trips`: daftar trip + pencarian asal/tujuan/tanggal/jam (lokasi di-geocode via Nominatim lalu dikirim sebagai lat/lng). `/trips/new`: publish trip (`POST /trips`, `departure_time` dikonversi ke ISO dengan offset). `/trips/[tripId]`: detail, anggota, trip serupa (`/trips/recommended`), form ajukan join, panel driver (terima/tolak request, ubah status trip), dan rating setelah trip `completed`. `/requests`: permintaan masuk untuk trip yang dipublikasikan + trip yang diikuti. `/chat/[tripId]`: chat dengan polling 4 detik memakai `?after=`. Karena backend belum punya endpoint "siapa saya", peran driver disimpulkan dari `GET /trips/{id}/requests` (sukses = driver, 403 = bukan). Field "deskripsi" di form buat trip dihapus karena tidak ada di kontrak API; field "ID kendaraan" ditambahkan karena `POST /trips` mewajibkan `vehicle_id`. Keterbatasan yang diketahui: halaman login/register/profil belum terhubung (auth ada di branch lain), belum ada endpoint daftar kendaraan, dan request `pending` milik passenger belum bisa ditampilkan.
**File yang terdampak:** frontend/src/lib/api/client.ts, frontend/src/lib/api/types.ts, frontend/src/lib/api/use-api.ts, frontend/src/lib/api/geocode.ts, frontend/src/lib/format.ts, frontend/src/components/ui/error-notice.tsx, frontend/src/features/trips/trip-card.tsx, frontend/src/features/join-requests/request-list.tsx, frontend/src/features/ratings/rating-panel.tsx, frontend/src/app/(main)/trips/page.tsx, frontend/src/app/(main)/trips/new/page.tsx, frontend/src/app/(main)/trips/[tripId]/page.tsx, frontend/src/app/(main)/requests/page.tsx, frontend/src/app/(main)/chat/[tripId]/page.tsx, frontend/src/app/globals.css, frontend/.env.example

## [2026-11-19] Autentikasi frontend dari develop + guard server per halaman

**Jenis:** Fitur baru
**Deskripsi:** Membawa implementasi auth dari `develop` ke working directory: halaman login/register/profil, form (`features/auth/*`), klien auth (`lib/auth/*`), helper server `lib/server/auth.ts` (`requireCurrentUser` membaca cookie `lelaku_session` dan memanggil `/auth/me`), `(main)/error.tsx`, unit test vitest, `package.json`/`package-lock.json`, dan `globals.css` dari develop. Halaman `(main)` hasil integrasi API sebelumnya dipecah: `page.tsx` kini server component yang memanggil `requireCurrentUser()` di setiap render lalu merender view client (`features/trips/*-view.tsx`, `features/join-requests/requests-view.tsx`, `features/chat/chat-view.tsx`). Ditambah tombol "Keluar" di header (`features/auth/logout-button.tsx`) yang memanggil `POST /auth/logout`. CSS integrasi API ditambahkan kembali setelah `globals.css` diganti versi develop. Catatan: `package.json` develop mengunci `next@15.2.0`, yang ditandai npm punya celah keamanan (CVE-2025-66478); sebaiknya dinaikkan ke versi patch.
