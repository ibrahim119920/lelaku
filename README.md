# lelaku

Lelaku memungkinkan pengguna mempublikasikan rencana perjalanan dan menemukan teman seperjalanan melalui intelligent trip matching. Sistem merekomendasikan titik pickup yang efisien, mendukung permintaan perjalanan bersama, serta menggunakan AI-assisted risk detection untuk mendeteksi aktivitas mencurigakan.

## Menjalankan project

Pastikan Node.js 20 atau versi yang lebih baru sudah terpasang, lalu jalankan:

```bash
npm ci
npm run dev
```

Server development tersedia di `http://localhost:3000`.

### Pemeriksaan kualitas

```bash
npm run lint
npm run typecheck
npm run test
npm run build
```

### Environment variable

Salin `.env.example` menjadi `.env.local`, kemudian isi nilai yang sesuai untuk environment lokal. Jangan commit file `.env.local` atau nilai secret ke repository.
